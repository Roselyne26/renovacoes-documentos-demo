# Renovações de documentos — Demonstração

Projeto de portfólio em React, TypeScript e Next.js: consulta por competência, seleção de empresas fictícias, processamento simulado em lote, dashboard, filtros, histórico e exportação de relatório PDF de demonstração.

Todos os dados são fictícios. Não há integração com serviços de trabalho, banco externo ou emissão de documentos reais. A simulação é mantida na memória do navegador e reinicia ao recarregar.

Execute npm install e npm run dev. Para publicar na Vercel, importe este repositório, selecione Next.js e mantenha a raiz. Não configure variáveis de ambiente.

Esta cópia demonstra a interface e o fluxo de processamento. O sistema de trabalho é mantido privado. Não inserir informações reais.

## Como publicar, passo a passo

1. Crie um repositório público novo chamado renovacoes-documentos-demo.
2. Envie o conteúdo de ENVIAR-RENOVACOES ao GitHub. Envie a pasta src e os arquivos que estão ao lado dela; mantenha package.json na raiz.
3. Na Vercel, escolha Add New → Project e importe esse repositório novo.
4. Escolha Next.js e mantenha Root Directory como ./.
5. Clique em Deploy. Não configure chaves, senhas ou banco de dados.

A pasta de publicação contém apenas o código da demo. Ela não contém histórico Git, arquivos .env, bancos, backups, logos internos nem dependências instaladas.

## Validação

Verificação TypeScript, seleção de candidatos fictícios, processamento simulado, indicadores e geração do PDF foram testados localmente.
