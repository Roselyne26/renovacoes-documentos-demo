# Renovações de documentos — Demonstração

Projeto de portfólio em React, TypeScript e Next.js: consulta por competência, seleção de empresas fictícias, processamento simulado em lote, dashboard, filtros, histórico e exportação de relatório PDF de demonstração.

Todos os dados são fictícios. Não há integração com serviços de trabalho, banco externo ou emissão de documentos reais. A simulação é mantida na memória do navegador e reinicia ao recarregar.

Esta cópia demonstra a interface e o fluxo de processamento. O sistema de trabalho é mantido privado. Não inserir informações reais.
